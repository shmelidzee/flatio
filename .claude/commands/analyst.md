# /analyst

Запускает Product Analyst для работы с требованиями.

## Использование
```
/analyst [идея или задача]
```

## Примеры
```
/analyst хочу добавить аналитику цен по районам
/analyst нужна функция сравнения объявлений
/analyst
```

## Что делает
Читает агента из `.claude/agents/product-analyst.md` и выполняет его алгоритм:
1. Читает существующую документацию из Notion
2. Исследует рынок если нужно
3. Проектирует решение
4. Пишет черновик изменений требований
5. Запрашивает апрув PO перед записью в Notion

Если задача не указана — спрашивает что нужно сделать.
