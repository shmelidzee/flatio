# /docs

Запускает Technical Writer для обновления документации.

## Использование
```
/docs [pr-number]
```

## Примеры
```
/docs 15       — обновить документацию по изменениям из PR #15
/docs          — обновить документацию по последнему merge
```

## Что делает
Читает агента из `agents/technical-writer.md`:
1. Читает diff PR
2. Определяет какие файлы документации затронуты
3. Обновляет README.md, docs/api.md, docs/parsers.md, docs/architecture.md, docs/local-setup.md
4. Добавляет запись в CHANGELOG.md
5. Коммитит изменения: `docs: update after #N`

**Не делает пустой коммит** если документация не изменилась.

Обычно запускается автоматически через GitHub Actions после merge.
Используй вручную если автоматический запуск не сработал.
