# /qa

Запускает QA Engineer в быстром режиме — после коммита.

## Использование
```
/qa
```

## Что делает
Читает агента из `agents/quality-assurance-engineer.md` в быстром режиме:
1. Читает diff последнего коммита
2. Читает Acceptance Criteria из связанного Issue
3. Пишет unit тесты на реальные сценарии
4. Запускает весь suite (`./gradlew test`)
5. Возвращает результат: ✅ зелёный или ❌ красный с точным отчётом

Для полного режима перед milestone используй `/qa-full`.
