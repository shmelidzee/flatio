# /security

Запускает Security Engineer на PR параллельно с /review.

## Использование
```
/security [pr-number]
```

## Примеры
```
/security 15   — проверить безопасность PR #15
/security      — проверить последний открытый PR
```

## Что делает
Читает агента из `.claude/agents/security-engineer.md`:
1. Проверяет секреты и конфигурацию
2. Проверяет аутентификацию и авторизацию
3. Проверяет работу с данными пользователей
4. Проверяет защиту от инъекций
5. Проверяет парсеры (rate limiting, санитизация внешних данных)
6. Проверяет логирование
7. Оставляет comments с уровнем CRITICAL/HIGH/MEDIUM/LOW

**Запускать параллельно с `/review` — не ждать друг друга.**
